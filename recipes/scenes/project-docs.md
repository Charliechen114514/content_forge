# 场景:项目文档(project-docs)

| 层卡 | |
|------|------|
| 维度 | 场景 |
| 档位 | 项目文档 |
| 互斥 | scene 是单值键，一次选一份 |
| 相邻 | 验收判据归 review/project-docs，执行顺序归角色卡，事实与模板归目标项目 |
| 让位 | 用户指定的读者、版本、文档范围与目标项目规范优先 |

管辖声明:管项目文档任务的读者、体裁和起稿方向。适用于 README、安装指南、配置说明和使用教程；不管审稿判据、复审流程和目标项目的技术事实。

## 读者与体裁

默认读者第一次接触目标项目，说明对应当前检出的项目版本。用户指定了读者或版本，就按指定的来。

README 帮读者判断项目是否适用，并找到开始使用的入口。安装指南帮助读者完成安装。配置说明帮助读者选值和理解效果。使用教程围绕一个具体任务展开，不要求每种体裁都套同一份章节模板。

## 写作方向

用平实自然的中文写完整句子，以短句为主。把读者需要的背景、前置条件和操作效果讲完整，保留因果、条件与转折。概念优先直接解释，读者缺背景而确需类比时，用完回到当前操作或事实。正文不带聊天里的称呼、口癖、颜文字和情绪表演；技术解释仍按基座要求让作者或读者参与观察、操作或推导。

项目文档组合不选个人声音卡，因此写手与声音走查以本场景的写作方向为准。需要模仿具体作者时，由用户选择声音卡和真实语料，不凭文档体裁猜作者口气。

## 来源

- 从 speak-understandable 的项目文档组合迁入任务方向；验收判据归本仓 review/project-docs，正向操作归角色卡，不依赖原仓路径或编译器。
