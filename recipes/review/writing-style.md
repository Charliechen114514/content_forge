# 审稿:示例审稿卡(writing-style)

| 层卡 | |
|------|------|
| 维度 | 审稿判据 |
| 档位 | writing-style |
| 互斥 | review 维度一次一份 |
| 相邻 | 机械词形判罚归 rules/*.toml(humanizer_lint 执行),本卡管编辑判断 |
| 让位 | 与宪法或流程冲突时归 base 与 process，作者最新裁决最高 |

管辖声明:这是一张示例卡,示范审稿判据层的写法,条款保持通用。换成自己的审稿规约时同名替换本文件,烘焙链不变。

## 一、人称在场

每一个散文段落至少出现一次自然人称,人称要参与观察、动作、疑问或推导,只在名词前补所有格不算数。连续技术解释里,作者与读者不能同时消失。

## 二、结构与重写

编辑性改写以完整文件为最小单位,保留事实、代码、命令、路径、链接与证据,允许重排、分段和整段重写。只加几句解释或口语,不算完成重写。

## 三、去 AI 味

「不是 X,而是 Y」一类平衡句,删掉 X 再读,信息没少就直接写 Y。用力动词配抽象宾语(「释放价值」一类)要落到可观察的动作上。主语是物、动作缩在句尾的倒置句,把动作者和动词提到前面再写:「X 常常没有…可依赖」一类「可 V」收尾,动笔前先问谁在对它做什么,人找到了句子自然不倒。物视角的同病家族一并退回:名词短语悬在句首、后文没有动词接它的话题悬空句;主语与表语同根的同义反复句(「设备树长成一棵树」);先断言差异、后摆材料、读者没见过对照物就被灌结论的论证段,改成先让读者看见两样东西,结论随对照浮出。空泛拔高与模板收尾删除,收尾停在最后一个具体事实上。

## 四、证据

关键结论由真实输出、日志、源码或标准条款支撑，扩写不得发明源材料没有的原因或状态，否定、范围、条件与可能性在改写前后保持一致。
