# recipes/ 层卡正本

一张层卡只管一件事。开头第一张表是元数据(维度、档位、互斥、相邻、让位),接着一句管辖声明写清管什么、不管什么,然后是正文。条款必须落在管辖声明范围内,塞声明外的新关切算混装:该扩声明的扩声明,该立新维度的立新维度。

## 目录

- base/ — 基座,平台宪法,必装。
- process/ — 流程层,一次一份,按任务模式选。
- review/ — 审稿判据层。
- voice/ — 声音层,管语料读取策略,不抄名单。
- scenes/ — 场景层,按活挑(本仓不带业务场景,可自建)。
- roles/ — 角色卡,主控、写手、四道走查。

## 纪律

- 判据住审稿层,流程与模板住流程层,操作指令住角色卡,一处一个家,不抄第二份。
- 机械词形规则唯一维护在 tools/humanizer-zh/rules/(上游项目,原址不动),层卡不抄。
- review_gate.py 依赖的报告短语是机器侧正本,搬运时逐字保留。
- 每张卡的 `## 来源` 段登记出处与让位去向,该段与 ```lint 块在烘焙时剥除,不进角色包。
- 改完层卡必须重跑 `python3 tools/bake.py`,让 build/ 与正本同步,`--check` 用来核对。
